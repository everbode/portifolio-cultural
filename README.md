# Gerador de Portfólio Cultural — Sobrinho Soluções Digitais

Gerador estático de portfólio cultural, sem banco de dados e sem Supabase.

## Modelo 01 — PNAB Três Lagoas/MS

O modelo ajuda o agente cultural a organizar:
- identificação e área de atuação;
- trajetória cultural e linha do tempo;
- projetos e trabalhos realizados;
- comprovações e links;
- galeria de registros;
- contatos;
- impressão / exportação para PDF;
- backup local em JSON.

Os dados preenchidos ficam no navegador do usuário (localStorage). O projeto não envia dados para um servidor.

> Ferramenta independente. Não é sistema oficial da Prefeitura de Três Lagoas e não substitui a leitura do edital vigente.

Referência oficial: https://www.treslagoas.ms.gov.br/secretariasmunicipais/seturc/pnab-2/
